# Class identifier (3D landmark → orthodontic class)

## Data

- Input: `master_dataset.csv` (generated by `build_dataset.py`)
- Target: `class` (0=Class I, 1=Class II, 2=Class III)
- Covariate: `gender` (0=F, 1=M)

## Install

Use the workspace venv (already set up under `.venv`). Optional:

```bash
/Users/eck/Documents/yüksek-lisans/MorphoMark/.venv/bin/python -m pip install -r class-identifier/requirements.txt
```

## Run (nested CV)

```bash
/Users/eck/Documents/yüksek-lisans/MorphoMark/.venv/bin/python class-identifier/run_pipeline.py
```

Outputs:

- `class-identifier/outputs/cv_summary.json`
- `class-identifier/outputs/permutation_importance.csv`

## Train a final model (for single-subject prediction)

Nested CV is for *evaluation*. To predict a new subject, train a final model on all available data:

```bash
/Users/eck/Documents/yüksek-lisans/MorphoMark/.venv/bin/python class-identifier/train_final_model.py
```

Outputs:

- `class-identifier/outputs/final_model.joblib`
- `class-identifier/outputs/final_model_meta.json`

## Predict from a new .txt file

```bash
/Users/eck/Documents/yüksek-lisans/MorphoMark/.venv/bin/python class-identifier/predict_txt.py path/to/new_subject.txt --gender 0
```

Notes:

- The `.txt` format must match your training files (23 landmarks, same order).
- The flags `--include-aligned-coords` and `--no-gender` must match how the final model was trained.
